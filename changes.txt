[v0.9]

[fixes]:
0) fixed error with redirecting stdout output to file;
1) fixed space esccaping with '--rawDir' option on chunks download stage;
2) fixed incorrect behaviour in case when '.m3u8' playlist presented as 1 file, but with various timestamps;
3) fixed bug with converting media streams to '.flac'/'.mp3' audio formats, because of missing explicit audio-codec argument in ffmpeg's call;
4) fixed scenario on '--merge' stage, when only 1 file in 'raw' dir presented, and raw format is same as output format;
5) fixed bug on '--merge' stage when '--rawDir' is not empty but not include files with given 'raw' extensions;
6) functions for '--concat' (concat demuxer), --'tracks-overlay' (concat filter) and '--convert' now accepting paths in 2nd parameter, not just filenames (w/o using global variable);
7) fixed bug in calculation of required space before merging chunks.

[changes]:
0) added group of flags for setting custom and random HTTP headers for GET requests ('--download' stage): '--header', '--headers', '--headers-string', '--headers-file', '--random-headers';
1) rewritten and optimized download parsing logic; now HLS init files correctly processed in case when parameters changes in same playlist "on the fly" via #EXT-X-DISCONTINUITY + #EXT-X-MAP:URI tags (HLS init files in '--rawDir' now have special mark with '#' before extension after download, i.e.: 'segment1#.m4s', 'segment1.m4s', 'segment2.m4s');
2) 'merge' main function changed to comply with new chunks downloading logic;
3) '--output'('-o') argument now became '--outputName'('-o') to prevent mashings with '--outputDir' arg.
